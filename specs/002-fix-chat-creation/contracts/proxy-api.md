# Proxy API Contract

## Overview

The intermediary API exposes a single endpoint `POST /proxy/chat` that accepts a user message from a web plugin and routes it through Open WebUI to the appropriate assistant, returning the assistant's response.

## Endpoint: `POST /proxy/chat`

### Request

```json
{
    "username": "john_doe",
    "tenant_id": "a0000001-0000-4000-8000-000000000001",
    "message": "Estoy buscando audífonos, ¿cuáles tienes disponibles?",
    "chat_id": "optional-existing-chat-uuid"
}
```

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `username` | string | yes | External user identifier from the web plugin |
| `tenant_id` | string (UUID) | yes | Tenant identifier for assistant routing |
| `message` | string | yes | User message content |
| `chat_id` | string (UUID) | no | Existing chat ID to continue a multi-turn conversation. If omitted, a new chat is created. |

### Response (200 OK)

```json
{
    "assistant_response": "Tenemos disponibles...",
    "chat_id": "2f861733-9cc5-4920-b120-ecd43c754347",
    "user_id": "26eb0ae9-cb22-41c1-be28-d9d303e0bfd3",
    "assistant_id": "asistente-de-ventas",
    "tenant_id": "a0000001-0000-4000-8000-000000000001",
    "timestamp": "2026-06-06T23:30:00Z",
    "follow_ups": [
        "¿Qué autonomía tiene la batería?",
        "¿Qué garantía ofrece?"
    ]
}
```

| Field | Type | Description |
|-------|------|-------------|
| `assistant_response` | string | The assistant's reply text |
| `chat_id` | string | The Open WebUI chat ID (use for follow-up requests) |
| `user_id` | string | The provisioned Open WebUI user ID |
| `assistant_id` | string | The model/assistant name that responded |
| `tenant_id` | string | Echo of the requested tenant ID |
| `timestamp` | string (ISO 8601) | Response timestamp |
| `follow_ups` | string[] | Suggested follow-up questions (if generated by assistant) |

### Error Responses

#### 404 — Unknown tenant mapping
```json
{
    "detail": "Unknown tenant mapping"
}
```

#### 500 — User provisioning failed
```json
{
    "detail": "User provisioning failed"
}
```

#### 500 — Chat creation failed
```json
{
    "detail": "Chat creation failed"
}
```

#### 502 — Open WebUI unavailable
```json
{
    "detail": "OpenWebUI unavailable"
}
```

## Internal API Contract (Between Proxy and Open WebUI)

The proxy calls the following Open WebUI endpoints in sequence:

### Step 1: Create Chat
`POST /api/v1/chats/new`
```json
{
    "chat": {
        "title": "New Chat",
        "models": ["asistente-de-ventas"],
        "messages": [
            {
                "id": "user-msg-uuid",
                "role": "user",
                "content": "Estoy buscando audífonos...",
                "timestamp": 1780289781000,
                "models": ["asistente-de-ventas"]
            }
        ],
        "history": {
            "current_id": "user-msg-uuid",
            "messages": {
                "user-msg-uuid": {
                    "id": "user-msg-uuid",
                    "role": "user",
                    "content": "Estoy buscando audífonos...",
                    "timestamp": 1780289781000,
                    "models": ["asistente-de-ventas"]
                }
            }
        }
    }
}
```

### Step 2: Inject Assistant Message
`POST /api/v1/chats/{chat_id}`
```json
{
    "title": "New Chat",
    "models": ["asistente-de-ventas"],
    "messages": [
        { "id": "user-msg-uuid", "role": "user", "content": "...", ... },
        {
            "id": "assistant-msg-uuid",
            "role": "assistant",
            "content": "",
            "parentId": "user-msg-uuid",
            "modelName": "asistente-de-ventas",
            "modelIdx": 0,
            "timestamp": 1780289781000,
            "models": ["asistente-de-ventas"]
        }
    ],
    "history": {
        "current_id": "assistant-msg-uuid",
        "messages": {
            "user-msg-uuid": { ... },
            "assistant-msg-uuid": {
                "id": "assistant-msg-uuid",
                "role": "assistant",
                "content": "",
                "parentId": "user-msg-uuid",
                ...
            }
        }
    }
}
```

### Step 3: Trigger Completion
`POST /api/chat/completions`
```json
{
    "chat_id": "chat-uuid",
    "id": "assistant-msg-uuid",
    "messages": [
        { "role": "user", "content": "Estoy buscando audífonos..." }
    ],
    "model": "asistente-de-ventas",
    "stream": false,
    "session_id": "session-uuid",
    "background_tasks": {
        "title_generation": true,
        "tags_generation": false,
        "follow_up_generation": true
    },
    "features": {
        "code_interpreter": false,
        "web_search": false,
        "image_generation": false,
        "memory": false
    },
    "variables": {
        "{{USER_NAME}}": "",
        "{{USER_LANGUAGE}}": "es-ES",
        "{{CURRENT_DATETIME}}": "2026-06-06T23:30:00Z",
        "{{CURRENT_TIMEZONE}}": "America/Santiago"
    }
}
```

### Step 4: Mark Completion
`POST /api/chat/completed`
```json
{
    "chat_id": "chat-uuid",
    "id": "assistant-msg-uuid",
    "session_id": "session-uuid",
    "model": "asistente-de-ventas"
}
```

### Step 5: Fetch Final Chat (optional, for verification)
`GET /api/v1/chats/{chat_id}`

Returns the complete `ChatResponse` with persisted assistant response.
